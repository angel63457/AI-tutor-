# AI Tutor

Это простой сайт-репетитор, который помогает с:
- математикой;
- русским языком;
- программированием.

## Как открыть сайт

1. Откройте файл `index.html` в браузере.
2. Или загрузите репозиторий на GitHub и включите GitHub Pages.
3. Для этого:
   - откройте `Settings` → `Pages`;
   - выберите ветку `main` и корневую папку `/`;
   - сохраните настройки.

## Что умеет сайт

- выбор предмета;
- чат с готовыми ответами;
- объяснения по шагам;
- примеры задач и подсказки.

## Файлы проекта

- `index.html` — главный сайт;
- `README.md` — описание проекта.

Сайт можно легко дорабатывать: добавить реальные ответы ИИ, форму регистрации, уроки, задания и темы для каждого класса.
